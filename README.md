# Touhou 3D Danmaku Showcase (TH06 - TH20)

基于 **Three.js + WebGL + TypeScript** 打造的东方 Project 正作 15 部代表性符卡纯 3D 视觉演出与视频渲染工程.

## 特性一览

- **全 15 作 3D 符卡立体化**: 覆盖 `TH06 东方红魔乡` 至 `TH20 东方锦上京`, 使用 `InstancedMesh` 批处理 + 自定义 GLSL 着色器 + HDR 辉光/色散/引力透镜/时间静止后处理管线.
- **15 套独立定制演出标题**: 每作拥有专属排版字体, 纹章与入场动效, 支持连播模式无重叠无缝切换.
- **三机位运镜 + 横/竖屏双画幅**:
  - `自动动态运镜` / `3/4 固定斜角全景` / `自由拖拽锁视角` (连播切换时持久化生效).
  - 一键切换 `16:9` 横屏与 `9:16` 竖屏短视频构图 (含平滑 FOV 与视距自适应).
- **无缝连播音轨管线**: 支持导入本地正作原曲自动 `-14 LUFS` 响度统一, 并以柔和过渡桥拼接为无断轨总轨 `master_mix.mp3`.
- **离屏确定性 60fps MP4 批量渲染**: 内置 Chrome CDP + `ffmpeg-static` 逐帧渲染脚本, 零掉帧输出 1080p 60fps 纯净无 UI 成片.

## 快速开始

环境要求: Node.js 20+ (批量离屏渲染建议 Node.js 22+ 与 Chrome/Edge), `pnpm`.

```bash
pnpm install
pnpm run dev
```

启动后访问 `http://localhost:5173`.

### 可选: 构建本地 BGM 同步音轨

本仓库不包含任何版权音频文件. 如需同步 BGM, 请将 15 首正作原曲放入 `public/audio/raw/` (命名说明见 [public/audio/raw/README.txt](public/audio/raw/README.txt)), 然后执行:

```bash
pnpm run audio:build
```

脚本将自动在本地生成响度标准化后的分轨与无缝总轨 `public/audio/master_mix.mp3`.

### 可选: 离线批量渲染 60fps MP4

```bash
pnpm run build
node scripts/render-videos.mjs --fps=60 --parallel=2
```

默认输出至 `outputs/` (已加入 `.gitignore`), 涵盖横屏/竖屏与动态/固定斜角 4 组 1080p 60fps 成片.

## 常用快捷键

| 按键 | 功能 |
|---|---|
| `Space` | 播放 / 暂停 |
| `A` | 开关全 15 作无缝连播 |
| `C` | 切换机位 (自动动态 / 固定斜角 / 自由视角) |
| `P` | 切换画幅 (横屏 16:9 / 竖屏 9:16) |
| `H` | 纯净模式 (隐藏 / 显示全部控制 UI) |
| `T` | 开关底部演出标题 |
| `M` | 静音 / 取消静音 |
| `R` | 重播当前符卡 |
| `←` / `→` | 快退 / 快进 `0.5s` |
